# TaskFlow — Project & Task Management

TaskFlow is a responsive, interactive project and task management web application with persistent SQLite storage, categorized task lists, priority filtering, and state transitions.

## Features
- Task creation with title, priority (low, medium, high), category, and notes
- Filter by All, Active, Completed, and High Priority
- In-place task completion toggling
- In-place task deletion
- Summary analytics header
- Responsive layout supporting desktop and mobile devices
- REST API with SQLite WAL persistence
